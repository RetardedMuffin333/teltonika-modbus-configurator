# v0.3 Bulk Generator UI polish

The Bulk Generator now switches transport-specific controls based on the selected source type:

- RTU: RTU connection is enabled; TCP Host/IP and TCP port are disabled; ID labels use `Slave ID`.
- TCP: TCP Host/IP and TCP port are enabled; RTU connection is disabled; ID labels use `Unit ID`.

Loading an RTU or TCP template immediately synchronizes these controls.
