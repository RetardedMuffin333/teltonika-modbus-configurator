# RDF bulk clone regression case

Regression reproduced from a real v0.3 project: an existing `RDF_Test` device occupied input registers 1025-1030 and holding registers 1031-1033. Cloning two more devices previously reused/shifted the source addresses by one and produced collisions. The new allocator creates a fresh block per Modbus address space and advances each generated device by the full template block width.
